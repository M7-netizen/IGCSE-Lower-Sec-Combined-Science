# Self-learning Platform 付费自学平台

这里将独立开发面向学生的售课平台。目标用户是刚从中国来到新加坡、第一次学习 Physics、Chemistry、Biology，并且需要中文帮助过渡到英文科学学习的孩子。

## 单课学习闭环

```text
中英学习目标
→ 零基础概念搭桥
→ 分步讲解与图解
→ 英文术语训练
→ 即时检查与错误解释
→ 考试题与英文作答
→ 达标检查与复习安排
```

## 后续功能

- 三科中英课程路线图
- 学生账号与课程购买
- 免费试看与付费解锁
- 测验、错题本和学习进度
- 学生仪表盘与家长报告

第一阶段应先完成一节 Biology 样板课，再决定完整技术栈。

## Biology 课程顺序

平台的课程目录、上一课/下一课、解锁顺序、进度百分比和复习计划必须遵循 `../shared/syllabus/README.md` 中的标准顺序：

```text
B1 → B2 → B3 → B4 → B5 → B6 → B8 → B7 → B9 → B10 → B13 → B11 → B12 → B14 → B15 → B16
```

## 三科综合路线

平台首页、综合课程目录、跨学科复习和总进度以 `../shared/syllabus/TEACHING_ROADMAP.md` 的 Phase 0–6 路线为最高标准。Chemistry C12 实验技能贯穿相关课程，不作为最后才解锁的孤立章节。
