# Bilingual Notes 中英双语讲义

这里存放完整、集中、适合阅读和打印的双语讲义。

- `combined-science/index.html`：包含 Biology、Chemistry、Physics 的当前三科主讲义。
- `archive/biology-only.html`：三科合并前的 Biology 单科历史版本，仅用于回看，不再继续编辑。

- 三科内容目前统一维护在 `combined-science/index.html`，方便跨学科检索和使用 Stage 标签筛选。

讲义负责知识大纲、术语、图解、易错点和答题模板，不加入登录、支付与学习进度功能。

Biology 讲义的章节展示和授课顺序必须遵循 `../shared/syllabus/README.md`，不得简单采用 B1–B16 数字顺序。

三科讲义的总体授课编排必须遵循 `../shared/syllabus/TEACHING_ROADMAP.md`。各科讲义可以独立阅读，但应在相关章节显示明确的跨学科连接提示。
