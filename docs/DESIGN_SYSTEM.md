# Design System 设计规范

现有页面采用“现代纸质教材”风格：米白底色、深棕正文、衬线标题，以及红、蓝、绿三种语义强调色。整体安静、可信、不幼稚，适合继续作为两个产品的共同品牌基础。

## 现有视觉语言

- Paper `#faf6ee`：页面背景
- Ink `#241c1a`：标题与正文
- Soft Ink `#5c534e`：解释文字
- Red `#b3382c`：重点、警示和当前章节
- Blue `#2c5f7c`：常规知识卡与信息提示
- Green `#4a7a4e`：正向提示、植物与生态内容
- Georgia / 宋体：标题
- 系统无衬线字体：正文与界面

## 两个产品如何共享风格

- 讲义保留长页面、左侧章节导航、卡片、表格和答题模板。
- 自学平台使用相同颜色、字体和卡片语言，但将知识拆成短课时和逐步学习界面。
- 红、蓝、绿必须保持稳定语义，不作随机装饰。
- 手机、平板和桌面端均须可用；学生正文建议不小于 16px。
