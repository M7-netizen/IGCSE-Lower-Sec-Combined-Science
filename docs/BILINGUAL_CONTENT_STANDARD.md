# Bilingual Content Standard 中英双语内容规范

## 核心定位

英文是学校课堂和考试的最终输出语言，中文是帮助零基础学生理解概念的支架。双语教学不是逐句机械翻译，而是“先理解，再逐渐用英文表达”。

## 必须双语呈现的层级

- Subject 科目
- Topic 主题
- Chapter 章节
- Lesson 课时
- Learning objectives 学习目标
- Key vocabulary 核心词汇

## 单课内容结构

1. 中文课名与英文课名
2. 可观察、可检测的中英学习目标
3. 英文术语、中文义和简明英文定义
4. 用中文生活经验搭桥，再给准确英文科学表达
5. 图解或逐步示例
6. 每小节后的即时检查与错误解释
7. 英文 command words、得分关键词和 model answer
8. 明确的完成标准与下一步

初学阶段中文解释可以较多；巩固阶段先显示英文、中文作为提示；考试阶段题目和答案以英文为主。

## 商业课程质量要求

- 标明 syllabus 版本与适用年份。
- 学科、英文表达和移动端体验均经过检查。
- 图片、视频、讲义和题目具有商业使用授权或为原创。
- 练习题与反馈能够让孩子在没有老师介入时继续学习。
